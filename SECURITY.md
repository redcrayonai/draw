# Security reports

Report a suspected vulnerability privately to
[support@redcrayon.ai](mailto:support@redcrayon.ai).
If the repository offers **Security → Report a vulnerability**, you can use
that private reporting form instead.

Include the affected revision, the steps to reproduce the error, and its impact.
Use synthetic accounts and data. Do not attach credentials or private board content.
Do not put an undisclosed vulnerability in a public issue.

The maintainers review reports against the current main branch.
This project does not promise a response deadline or a security bounty.
